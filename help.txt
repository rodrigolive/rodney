rodney - Chrome automation from the command line

Browser lifecycle:
  rodney start [opts]             Launch Chrome (headless by default). Options:
                                    --show           visible browser window (maximized)
                                    --insecure, -k   ignore TLS errors
                                    --user-agent UA  override the User-Agent
                                    --human          humanlike input: curved pointer paths,
                                                     key-by-key typing, wheel scrolling
                                    --no-console     no console capture (it keeps the
                                                     Runtime domain on, an automation tell)
                                    --stealth        --human plus --no-console
                                    --timezone TZ    IANA zone pages see (e.g. Europe/Madrid)
                                    --lang LIST      languages pages see (e.g. en-US,en,es)
                                    --window WxH     window size (default headless: 1280x887,
                                                     a 1280x800 page area)
                                    --chrome-arg ARG extra Chrome switch, e.g.
                                                     --chrome-arg=--use-angle=gl; repeatable
                                    --replace        restart even if a session is already running
                                    --extension PATH load an unpacked dir or .crx/.zip
                                                     archive; repeat for several
                                    --cache          keep the HTTP/disk cache (off by default)
                                  On a running session, options are ignored (with a
                                  warning) unless --replace is given. Every session
                                  hides navigator.webdriver, sends the browser's real
                                  UA minus "Headless", and, behind a proxy, keeps
                                  WebRTC from revealing the host's own address.
  rodney connect <host:port>      Connect to existing Chrome on remote debug port
  rodney stop                     Shut down Chrome
  rodney status                   Show browser status
  rodney extensions               List extensions loaded into this session
  rodney version                  Print version

Navigation:
  rodney open <url> [opts]        Navigate to URL. Options:
                                    --wait load|domcontentloaded|none (default load)
                                    --no-wait      alias for --wait none
                                    --timeout SEC  override the default load timeout
                                    --expect-ok    exit non-zero on HTTP status >= 400
                                    --then-js EXPR   after load, eval EXPR and print its result
                                    --user-agent UA  override the User-Agent
  rodney back                     Go back in history
  rodney forward                  Go forward in history
  rodney reload [--hard] [--timeout SEC]   Reload page (--hard bypasses cache)
  rodney clear-cache              Clear the browser cache
  rodney no-cache <on|off>        Disable/enable HTTP cache for the session
                                  (persists across reloads; the disk cache only
                                  comes back with 'start --replace --cache')

Page info:
  rodney url                      Print current URL
  rodney title                    Print page title
  rodney html [selector]          Print HTML (page or element)
  rodney text <selector> [--timeout SEC]   Print text content of element
  rodney attr <selector> <name>   Print attribute value
  rodney pdf [file]               Save page as PDF

Interaction:
  rodney js [--timeout SEC] [--json] <expr> | - | --file <path>
                                  Evaluate JS; awaits returned Promises.
                                  '-' reads the expression from stdin,
                                  --file reads it from a path.
                                  --json: always emit valid JSON
  rodney click <selector>         Click an element
  rodney input <selector> <text>  Type text into an input field
  rodney clear <selector>         Clear an input field
  rodney file <selector> <path|-> Set file on a file input (- for stdin)
  rodney download <sel> [file|-]  Download href/src target (- for stdout)
  rodney select <selector> <val>  Select dropdown option by value
  rodney submit <selector>        Submit a form
  rodney hover <selector>         Hover over an element
  rodney focus <selector>         Focus an element
  rodney scroll <down|up> [PX]    Scroll the page (default 600px)
  rodney scroll <selector>        Scroll an element into view
                                  click, input, clear, hover and scroll act like
                                  a person in --human sessions or with RODNEY_HUMAN=1

Waiting (all accept --timeout SEC):
  rodney wait <selector>          Wait for element to appear
  rodney waitload                 Wait for page load
  rodney waitstable               Wait for DOM to stabilize
  rodney waitidle                 Wait for network idle
  rodney sleep <seconds>          Sleep for N seconds

Screenshots:
  rodney screenshot [-w N] [-h N] [file]  Take page screenshot
  rodney screenshot-el <sel> [f]  Screenshot an element

Tabs (indices are stable across calls; target ids are stable for the tab's life):
  rodney pages                    List all pages/tabs (shows target id per tab)
  rodney page <index|target-id>   Switch active tab by index or target id
  rodney newpage [url]            Open a new tab; prints its target id ("target: ID")
  rodney closepage [index|target-id]  Close a tab (defaults to the active one)

Element checks:
  rodney exists <selector>        Check if element exists (exit 1 if not)
  rodney count <selector>         Count matching elements
  rodney visible <selector>       Check if element is visible (exit 1 if not)
  rodney assert <expr> [expected] [-m msg]  Assert JS expression (truthy or equality)

Accessibility:
  rodney ax-tree [--depth N] [--json]       Dump accessibility tree
  rodney ax-find [--name N] [--role R] [--json]  Find accessible nodes
  rodney ax-node <selector> [--json]        Show accessibility info for element

Console capture:
  rodney console [--pattern <re>] [--limit N] [--errors-only] [--raw]
                                  Print captured console messages and
                                  uncaught exceptions from the active
                                  session. Defaults to last 50.
  rodney console --clear          Clear the captured console log

Options (may appear anywhere in the command):
  --local                         Use directory-scoped session (./.rodney/)
  --global                        Use global session (~/.rodney/)
  --session NAME                  Isolate state under sessions/NAME (own Chrome)
  --target ID                     Operate on the tab with this target id
  --page <idx|substring>          Target a specific tab for THIS command only
                                  (numeric index, or case-insensitive URL/title
                                  substring). Does not change the active page;
                                  wins over --target.
                                  Works with js, click, input, exists, etc.
  --version                       Print version and exit
  --help, -h, help                Show this help message

By default, commands auto-detect: if ./.rodney/state.json exists in the
current directory, the local session is used; otherwise the global session.
Use "rodney start --local" to create a directory-scoped session.

Running multiple agents in parallel (no conflicts):
  Isolation (simplest) — give each agent its own Chrome:
    RODNEY_SESSION=agent1 rodney start      # or --session agent1
    RODNEY_SESSION=agent1 rodney open ...    # each agent: set it once, use normally
  Shared browser — one Chrome, each agent pins its own tab:
    id=$(rodney newpage https://site | sed -n 's/^target: //p')
    RODNEY_TARGET=$id rodney open https://site   # or --target $id on each command

Environment:
  RODNEY_HOME                     Override data directory (default: ~/.rodney)
  RODNEY_SESSION                  Isolate state under sessions/NAME (own Chrome)
  RODNEY_TARGET                   Operate on the tab with this target id
  RODNEY_START_FLAGS              Default 'start' options, e.g. "--show --timezone
                                  Europe/Madrid" (command-line options win)
  RODNEY_HUMAN                    1/0: humanlike input on/off for this command
  RODNEY_NO_CLIENT_HINTS          Hosts whose pages get no User-Agent client hints
                                  (default reddit.com,redd.it,redditmedia.com, where
                                  recent Chrome sending them is challenged; none: off)
  ROD_CHROME_BIN                  Browser to launch (default: rod's Chromium)
  ROD_TIMEOUT                     Default timeout in seconds (default: 30)
  RODNEY_DEBUG                    Show full Go stack traces instead of clean errors

Exit codes:
  0  Success
  1  Check failed (exists, visible, assert, ax-find returned no match)
  2  Error (bad arguments, no browser, timeout, etc.)
